What the learner will do

Play resumes the earliest unfinished curriculum stage, not the last game visited. Explore opens the six-fort route. Fort 1 contains eight sequential named games, but this demo implements only MathFly and NumberLineJump. Each attempt has three lives; a wrong answer or a ten-second question timeout loses one life and advances to a new question.

English is the base language with spoken explanation narration now. Text and audio will use stable keys so Marathi can be added through settings later. Age group and syllabus are not confirmed; the old COD Class 1 scope must not be silently carried over.

Assets and source status

The client has uploaded a Client Game Assets folder containing StartPage, FortPage, Fort1, MathFly reference material and sprite sheets, DayBG/NightBG and a bird MP4. Their presence is not proof of correct slicing, animation, usable narration or working screens. No new asset generation is claimed.

nipun/development has been created from cod/visual-preview in the existing private game repository. The intended new local clone has not been verified. COD’s eighteen local Pip/layout files remain preserved and unpushed. Do not overwrite them while starting NIPUN work.

Target and next checkpoint

The requested latest delivery target is Sunday, 1 November 2026, with an earlier preview if ready. This is a target, not a verified completion promise. Next: inspect and map the client assets, preserve the COD checkpoint, establish editable NIPUN screens, then prove one narrated question loop before expanding both games and building WebGL.
