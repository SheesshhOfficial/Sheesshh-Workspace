Optional LearningGarden verification

  1. Create a new Unity 6 / 6000.x 2D Built-In project. No specific editor patch is certified.
  2. From the previously delivered starter, copy the complete Assets/LearningGarden folder into the project’s Assets folder. Avoid a nested Assets/Assets path.
  3. Allow import and compilation to finish. Resolve any Console errors first. The source uses uGUI; the official Unity UI package must be available.
  4. Set Active Input Handling to Both or Input Manager (Old) as documented in the starter. Save work before any Unity-requested restart.
  5. Save open scenes, then choose Tools > Learning Garden > Create Starter Scene. The builder uses a uniquely named scene and stops on dirty content rather than discarding it.
  6. Choose a 16:9 Game view and press Play. The UI is constructed at runtime.
  7. Complete Count Apples, Find Shapes and Memory Pairs. Try a wrong answer, replay and sound toggle. Capture the actual result and any Console errors.
  8. Exit Play, then run Tools > Learning Garden > Run Core Checks. Retain the output; this does not replace manual testing.

The complete delivered starter README and manual checklist remain the source of detailed setup guidance. A device build needs explicit platform setup and the generated scene added to the active Build Profile; no build is implied by opening the project.

What to record

Editor version, platform/device, orientation, activity, expected result, actual result, Console output and screenshot. Mark each check Passed, Failed or Not Run. Do not turn a missing report into a pass.

Minimum manual scenarios

  • Correct, incorrect and repeated choices; no duplicate progress.
  • Home, replay, exit mid-round and opening/closing settings.
  • Memory mismatch turn-back, all four pairs and restart.
  • Keyboard focus and touch controls on the chosen device.
  • Sound mute/unmute without resetting the game.
  • Grown-up reset confirmation and preservation of unrelated preferences.
